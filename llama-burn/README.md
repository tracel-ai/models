# Llama Burn (Archived)

This implementation is archived and no longer maintained.

Llama support has moved to [Burn LM](https://github.com/tracel-ai/burn-lm), where it is actively
developed and improved in the `burn-lm-llama` crate. Burn LM supports Llama 3, Llama 3.1,
Llama 3.2, and TinyLlama, with tooling for large-model inference and training.

The former `llama-burn` source remains available in this repository's Git history.
